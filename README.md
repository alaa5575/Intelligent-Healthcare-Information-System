
# Intelligent Healthcare Information System (IHIS)

An Intelligent Healthcare Information System designed to digitize hospital workflows, manage patient records, and support clinical services through modular web-based applications and AI-powered solutions.

## Project Overview

IHIS is a collaborative healthcare technology project developed to support hospital operations through an integrated digital platform.

The system includes multiple healthcare modules, including patient management, appointments, dental services, laboratory services, radiology, and pharmacy.

## My Contribution

This was a collaborative team project. My primary responsibility was developing the Dental Clinic Module and translating clinical dental workflows into a functional digital system.

I contributed to implementing dental-specific functionalities, including integrating the AI-based dental caries detection module into the broader healthcare information system.
